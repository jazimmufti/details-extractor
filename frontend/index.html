Official Meta Instagram Messaging Rules

Why public @usernames cannot receive cold DMs via API

1. Public Discovery ≠ Messaging Recipient

Finding a creator's public profile (e.g. instagram.com/mrbeast) identifies their username, but Meta's official API strictly forbids cold direct messages to arbitrary usernames to prevent spam.

2. Instagram-Scoped ID (IGSID) Requirement

Meta requires a numeric Instagram-Scoped ID (IGSID). This ID is uniquely generated when a user interacts with your connected Instagram Professional account (such as sending an inbound DM or commenting on a post).

3. 24-Hour Messaging Window

Once a creator messages your account, Meta opens a standard 24-hour customer service window allowing your app to respond via Graph API.

4. Development & Tester Mode

While your Meta App is in Development Mode, messages can only be delivered to registered App Testers or accounts with established IGSIDs.
